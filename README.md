# Godius Eternal War キャラクターシミュレーター

オンラインゲーム「Godius Eternal War」のキャラクター育成をシミュレーションするWebツールです。職業・レベル・パラメータ・スキル・習得魔法などを入力すると、必要な「力の玉」の量、到達可能レベル、装備性能などを計算して表示します。

## 主な機能

- **キャラ診断**：職業・副業・レベル（LV99まで）・パラメータ・スキル・習得魔法から力の玉の使用内訳と過不足を診断します。
- **必要玉数シミュレーター**：入力変更に応じて必要玉数・到達可能レベル・過不足をリアルタイムに再計算します。
- **玉数計算**：スキルは期待値方式（LV17まで）と固定方式（LV18以降）で算出します。
- **保有想定と損得判定**：現構成から想定される保有玉数を表示し、残玉入力時は差分から得／損を判定します。
- **課金衣装（+5%）**：最大HP/MP/SPを5%増（切り上げ）として平均値表示・自動補完・診断結果に反映します。
- **装備シミュレーター**：装備品とパラメータから WC・HC・AC・DC・重さなどを計算します。
- **おまけ情報**：魔法（火炎／冷凍／聖／援護）、 歌、錬金、応急 の情報を表示します。
- **セーブ／ロード**：入力内容を localStorage のキャラスロットに保存・復元します（スロットは追加可能）。
- **共有URL**：現在のキャラ状態をURLに埋め込んで共有できます。

## 使い方

`index.html` をブラウザで開くだけで動作します。ビルドやサーバーは不要です（静的HTML/CSS/JavaScript）。

1. 職業・副業・レベルを選択します。
2. パラメータ・スキル・習得魔法を入力します。
3. 診断結果や必要玉数がリアルタイムに表示されます。
4. 必要に応じてセーブや共有URLの生成を行います。
